SpaceScavenger

Описание проекта:
SpaceScavenger — это простая 2D-игра на Python, в которой игрок управляет космическим кораблём и собирает ресурсы, избегая метеоритов.

Управление:
* WASD или стрелки — движение корабля.
* Собирай жёлтые объекты, чтобы получать очки.
* Избегай метеоритов, чтобы не терять жизни.

Цель игры:
Набрать как можно больше очков и сохранить жизни.

Технологии
* Python
* Pygame
